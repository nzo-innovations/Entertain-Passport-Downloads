# Entertain Passport downloads

Public installers for the Entertain Passport client apps. The source code is private - this repository only holds release files.

| App | For | Latest release |
| --- | --- | --- |
| EP Office (Windows x64) | Event organizers, artist managers, artists, company / venue owners and gate staff | [office-v0.2.0](https://github.com/nzo-innovations/Entertain-Passport-Downloads/releases/tag/office-v0.2.0) |

The same download is on the organizer sign-in page: https://www.entertainpassport.com/organizer/login

Each release lists the installer's SHA256. To check a download in PowerShell:

```powershell
Get-FileHash .\EP.Office-Setup-0.2.0-x64.exe -Algorithm SHA256
```
